# CCNA-Labs
Hands-on CCNA networking labs demonstrating routing, switching and troubleshooting

This repository contains hands-on networking labs I completed while studying for the CCNA.
Each lab includes configurations, topology diagrams, and verification output.

## Labs

### 🔹 VLANs & Trunking
- VLAN creation
- 802.1Q trunking
- Inter-VLAN routing
- Verification using ping and show commands

### 🔹 Routing (OSPF / Static)
- Single-area OSPF
- Static routing
- Route verification

### 🔹 Network Services
- DHCP
- DNS basics
- NAT
